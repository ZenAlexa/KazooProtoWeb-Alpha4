## 🐛 常见问题和解决方案

### Q1: 页面加载失败，Console 显示模块错误

**原因**: ES6 模块需要 HTTP 服务器
**解决**: 确认访问 http://localhost:3000 而不是 file:// 路径

### Q2: 麦克风权限一直是"已允许"，无法测试拒绝场景

**解决方案**:

**Chrome**:
1. 点击地址栏左侧的 🔒 图标
2. 点击 "网站设置"
3. 找到 "麦克风" 下拉菜单
4. 选择 "阻止"
5. 刷新页面

**Firefox**:
1. 点击地址栏左侧的 🔒 图标
2. 点击 "清除权限和重新加载"
3. 刷新页面

### Q3: Console 日志太多，看不清楚

**解决方案**:
1. 点击 Console 的垃圾桶图标清空日志
2. 刷新页面重新测试
3. 只复制最后 10-20 行相关日志
